## Verification

The complete C++ suite passed **210/210** checks in 271.55 seconds. The exporter
tool suite passed **405 tests across 22 groups**. Following this run, a cosmetic
map-zoom label adjustment moved it clear of the selected-fleet/inspection panel;
the client was rebuilt and all **27 exported-game validators** passed again on
the exact final executable. Package allowlist checks were repeated as well.

Actual exported checks cover startup and independent Unicode save slots,
save/reload equality, navigation and input ownership, support bundles, tactical
battle orders and observer filtering, research, civilian/military fleets,
shipbuilding, construction, systems and inspection, supply/economy/colonies,
planetary placement/cancellation, freight, normal fresh progression, exploration,
survey, settlement preparation, earned settlement, colony/outpost orders,
local travel, galaxy backgrounds, ship artwork and diplomacy.

Planetary input/save/reload checks passed at 1280×720, 1920×1080 and 2560×1440.
Visual review included the new planetary screen, battle, fitted overview,
regional scenery and selected fleet panel. The fixed star background fills the
regional view below nebulae and map objects; the overview retains galaxy artwork.

The final packaged 50,000-system New Game replay used seed 8057 and the
Pelagic High-Pressure profile. Creation, independent save and completion took
15.85 seconds. Reload plus overview/regional/system input validation took
17.85 seconds. The requested pre-existing save was preserved. The resulting
save was 439,218,730 bytes, and all 50,000 catalog markers were present in overview.
These totals include UI automation and capture, not just generation/loading.

That navigation replay measured a 17.404 ms mean frame and 17.694 ms p95,
including cold loading, save service and transitions. Mean scene preparation was
6.641 ms. The save-service update reached **274.415 ms**, so this is not a claim
of hitch-free gameplay or universal 60 FPS. It does not certify late-game scale.

## ENGINE CAPABILITIES ADDED / EXTENDED

- Core nearby-world planning reuses a stable per-system planet index. The
  50,000-system generation benchmark fell from **36,229.4 ms to 3,588.75 ms**
  on this host. The full 440,690,994-byte output and fingerprint
  `15864570924479060606` stayed identical. This is a single isolated benchmark,
  not total startup time. Stable-ID ordering and authoritative viability rules
  remain unchanged; there is no new persisted cache.
- Atomic streaming saves reduce temporary serialization memory. The writer owns
  its callback safely, rejects empty callbacks and preserves atomic failure/backup
  behavior. Unicode path classification no longer depends on the Windows ANSI
  code page; player/developer save boundaries remain enforced.
- Integrated C++ 3D motion and collision queries, corvette hull geometry,
  generated planet relief and mesh picking; optional saved combat depth retains
  legacy planar-save compatibility. These consume shared Engine primitives and
  authoritative Core commands, rather than a second UI simulation.
- 25k/50k setup, spatial lane/navigation indexing, compact distant markers and
  bounded image cropping extend the scale of the native map. The supplied regional
  star image remains a fixed, full-viewport background.
- Reviewed planetary assets/provenance are now included in both CMake staging
  and export. Versioned archives carry release notes, checksums and truthful
  source provenance. Export input replays follow the current Controlled Assets UI.

Interfaces, ownership, test details and future reuse are documented in
`docs/ENGINE_CAPABILITIES.md` and `docs/NATIVE_3D_SCALE_INTEGRATION_REPORT.md`.
The earlier report's generation timings precede the nearby-world indexing change.

## ENGINE LIMITATIONS REMAINING

- The maximum campaign size is 50,000. Full snapshot capture and full-document
  load still consume whole-world memory; saves remain large uncompressed JSON.
- 3D motion/query integration is not a complete rigid-body/contact solver.
  Detailed models for every ship, authoritative physical terrain interaction,
  ground combat and full province/resource simulation remain unfinished.
- Existing scene/detail budgets remain, including 32 detailed tactical corvettes.
  Lighting/shadows/PBR, extensive late-game performance and complete earlier-game
  parity remain outstanding. Godot version-19 saves are not imported.
- This is an unsigned local alpha. Separate clean-device certification, full
  release/Steam gates and public hosting are not complete.
- This host's C: drive was full during validation. Tests used isolated save/temp
  folders on D:. Normal saves use LocalAppData on C:, so free space there before
  normal play; large saves also need temporary-write and backup space.
