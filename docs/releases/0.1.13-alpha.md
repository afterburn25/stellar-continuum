# Stellar Continuum 0.1.13 Alpha

Native Windows alpha, powered by Stellar Engine 0.1.62.

- New galaxies support 25,000 and 50,000 systems. Indexed navigation and smaller distant star markers keep the full catalog available at overview zoom.
- Nearby expansion-world planning uses one planet index instead of repeated full-catalog scans, preserving the generated campaign for the same seed.
- Saves stream to disk through atomic replacement, reducing temporary save-writing memory. Existing native Player17 saves remain supported.
- New campaigns and saves support non-English folder and file names; player/developer save isolation remains enforced.
- The planetary screen is the sole native colony interface. The retired surface workspace, navigation, renderer and packaged ground assets have been removed.
- Generated solid planets have 3D relief with matching selection. Tactical corvettes use solid 3D geometry; combat movement and saved orders support depth. Alt + mouse wheel changes the selected formation's depth.
- The supplied star background covers the regional star map and stays fixed during pan and zoom. Nebulae and map objects appear above it. The zoomed-out galaxy artwork is preserved.
- Galaxy morphology, population profiles, nebula regions, research, construction, exploration, settlement, freight, diplomacy and developer diagnostics are included in this native alpha.

This remains an incomplete native migration. Full rigid-body collision response,
detailed models for every ship, physical terrain interaction, and campaigns beyond
50,000 systems remain unfinished. Large save files still take memory and time to
load. Godot version-19 saves are not imported. See the accompanying validation
report for tested flows and measured limits; a successful package check does not
establish complete gameplay parity or clean-machine certification.
