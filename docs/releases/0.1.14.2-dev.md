# Stellar Continuum 0.1.14.2 Development Preview

In-development native preview, powered by Stellar Engine. This package is built
from the `game/ui-visual-overhaul` workstream and is not a numbered alpha
release; it exists so the packaged game can be exercised on clean machines and
through the full validator battery.

## Highlights since 0.1.13 Alpha

- The native client is the shipping runtime: SDL3 windowing, Vulkan rendering,
  stellar photospheres, PBR planet materials, atmospheres, gas-giant bands,
  rings, shadows and emissive ships driven by authoritative campaign state.
- Windows accessibility bridging exposes interactive controls through UI
  Automation (Invoke, Toggle and RangeValue patterns plus focused-label and
  control/range announcements).
- Per-surface text scaling honors the accessibility TEXT SIZE setting through
  the canonical type ramp; settings surfaces (audio, video, general, voice,
  controls) persist through the settings hub with save/cancel/restore
  semantics.
- Save-fenced New Game preserves the live campaign through cancel, exit and
  create paths; restarted campaigns occupy independent save slots.
- Replay hardening: internal smoke saves journal a synthetic quicksave command
  so they remain replay-verifiable; navigation and system-travel validators
  record, restore and replay command/checkpoint streams.
- The packaged validator battery now exercises every standalone client
  smoke/check flag — the restart lifecycle family, quick find, stellar
  eruption and the full developer-index replay — plus all six settings checks
  at startup and pause locations.

## Known limitations

- Full graphical parity is not certified (`graphicalParity: false`); this is a
  development preview, not a complete-migration claim.
- The UIA fragment tree is partial and non-Windows accessibility backends are
  not implemented.
- Godot version-19 saves are not imported; native Player17 saves remain the
  supported format.
- A successful package check does not establish clean-machine certification or
  complete gameplay parity. See the accompanying handoff for tested flows.
