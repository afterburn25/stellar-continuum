Existing native Between/SquaredBetween stay unchanged unless an actual parity failure proves a correction necessary.

The local system chart is normalized presentation geometry that consumes authoritative simulation time; it is not physical orbital distance or light-year fuel. Keep the existing0.82 gate radius and rate max(0.1,0.9*max(0.1,StrategicSpeed)/22). Do not infer travel months from chart scale. No scene/camera dependency belongs in this native port. Input consists of complete native FleetState, Vec2 and const StellarSystem spans. No knowledge, route planning, fuel debit, surveying, settlement or campaign ticking is implied.

Public operations: finite(Vec2), local transit rate, gate towards, Begin, Advance, Complete, RemainingDays, RemainingChartDistance; plus chart interpolation and physical distance from fleet. Use distinct descriptive names in a `fleet_transit.hpp` rather than overloading a generic advance or duplicating existing interstellar distance APIs.

Begin sets phase and sanitizes nonfinite start/target to zero, copies start to position, resets progress. Advance returns0 without mutation for nonpositive/nonfinite days. It sanitizes temporary start/position/target as the source does, but does not rewrite every original field. A nearly complete remaining distance snaps position/progress and spends0. Preserve source float versus double evaluation: vector lengths, total, completed fraction and Lerp input are float; available days, rate, final progress and spent time are double. Do not replace Vector2.Lerp with an algebraically equivalent formula without exact-source fixtures. Complete and RemainingDays deliberately do not sanitize vectors. IEEE NaN behavior is preserved, not silently converted into a valid route.

RemainingChartDistance copies planned waypoints, or the final destination if the stored list is empty. An empty route returns RemainingDays*Rate without building a system dictionary. A nonempty route rejects duplicate system IDs in source order, even if a duplicate is not on the route. Preserve current-phase handling: local arrival may skip a route head equal to the arrived system; local departure/arrival include their current remaining chart leg. An idle current system adds the local leg to its outbound gate. Unknown previous/current target IDs skip that iteration without advancing previousId, but an absent following endpoint accessed with the source dictionary index throws. The accumulator is FLOAT (source conditional initialization), rounded after each segment; return conversion to double occurs only at the end. This query never mutates routes or fleets.

FromFleet resolves origin from TransitOriginSystemId while warping, otherwise CurrentSystemId. If origin depth and target depth are both absent, it uses legacy float2D distance before considering waypoint depth. Otherwise it interpolates origin depth toward the first remaining waypoint (or destination fallback) using clamped transit progress while in warp; absent depths become0. Compute final3D separation in double using the fleet's current chart position. Missing origin and missing waypoint follow actual FirstOrDefault behavior. Preserve list order and first matching system identity. No extrapolation beyond clamped progress and no inferred destination from a visual marker.
