# Founding civilizations and nearby expansion

Frozen interface: `core/include/stellar/core/civilization_catalog.hpp`. This slice preserves CivilizationSeeder, founding leadership, SpeciesHomeworldPlanner's constrained fallback/within-system resolver, and NearbyHabitableWorldGuaranteePolicy. It ends immediately before ColonySeeder. It is not a playable campaign, a full species definition, leadership succession, or a save format.

Preserve template RNG draw order and unchecked seed arithmetic; canonical human Earth reservation; nonhuman player selection with and without rivals; ancient flags; founding office identity/order; home naming and name collision resolution. Preserve original greedy/global expansion assignment, transactional restoration, search budget, distinct expansion slots, 340 light-year distance cutoff, stable-star exclusions, natural candidate preference, and fallback environment/mass changes. SpeciesPlanetaryHabitabilityEvaluator is a policy wrapper around the already ported natural evaluator: naturally viable requires naturally_colonizable and no native pre-warp civilization. Legacy habitat-supported fallback is not naturally viable.

The full founding pipeline retains the original GalaxyGenerator stage order: initial bodies, civilization seeding, home renaming/unique names, regenerated bodies, nearby guarantees. Only the original specific placement failure triggers reset to original systems, constrained home planning, home replacement, renaming/regeneration, and a second guarantee pass. No new balance or silent rescue policy.

Ownership: civilization worker owns `core/src/civilization_catalog.cpp` and `core/src/founding_catalog.cpp`; expansion worker owns `core/src/species_homeworlds.cpp` and `core/src/nearby_habitable.cpp`. Coordinator owns the header, CMake, application, source-generated oracle and native comparisons. Oracle cases must exercise actual preserved C# methods, zero rivals, every player species, ancient limits, legacy catalogs, seed boundaries, constrained search/failure, global reassignment, and founding output. No old implementation is removed. No integration/main merge is authorized by this milestone.
