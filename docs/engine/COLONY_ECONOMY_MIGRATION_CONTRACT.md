# Colony founding and economic support calculations

Frozen interface: `core/include/stellar/core/colony_economy.hpp`. Port existing ColonySeeder, complete ColonyState/CivilizationEconomyState data defaults, ColonyLaborEconomy, ColonySustenanceCapacity/Reserves and TreasuryHealth. Preserve ancient/ordinary balances and populations, canonical Earth/Luna/Mars identities and dependent settlements, legacy bodyless behavior, insertion order and IDs, stored food/water units, and all initial zero/default fields. Budget units remain the reference simulation's normalized ledger; do not invent a new currency conversion.

SurfaceBuilding is data only. Capacity accepts the explicit food/water/housing projection of authoritative SurfaceColonyOutput; it does not calculate building power/staffing or silently replace SurfaceConstruction. Native CLI may pass zeros for newly seeded colonies, which contain no surface buildings at this stage. Preserve biological capacity interpretation, exact solvent/area/infrastructure clamps and limiting-supply ties. Reserve preview is immutable; advance changes only the two reserve fields and follows the original interval math, including zero-day behavior. Labor preserves population clamps and represented jobs; treasury preserves finite input validation, arrears threshold, and infinite surplus runway.

This gate ends at colonies/initial economy before FleetSeeder and the remaining campaign setup. It does not implement EconomySimulation's complete credit flow, operations funding, industry/science production, population mutation, surface power/workforce allocation, demographics, logistics, or save-v16. Avoid claiming a full economic tick or graphical parity.

Ownership: colony worker owns new `core/src/colony_economy.cpp`; reference worker owns new `tests/Stellar.Colony.ParityGenerator` and `native-tests/fixtures/colony-economy.json`; coordinator owns shared header/CMake/CLI/native comparison tests. Actual C# reference fixtures must cover seeded ordinary/ancient/canonical/legacy colonies and all economy defaults, missing Sol settlement failure, all four species, support deficits/reserve exhaustion/replenishment, preview nonmutation, represented jobs/unemployment, and treasury boundary/failure cases. Gameplay source remains unchanged.
