# Colony biology and environmental support migration

Frozen interface: `core/include/stellar/core/colony_biology.hpp`. This gate supplies the demographic and habitat facts used by the preserved EconomySimulation; it does not mutate population, adapt species, apply policy, create cohorts, or implement full SpeciesDefinition.

Sources: `SpeciesCatalog.cs` authored physiology/life-history/metabolism; `SpeciesDemographicPressure.cs`; `SpeciesMetabolism.cs` founding/unadapted envelope; `SpeciesPlanetaryHabitability.cs` current colonization-policy wrapper; `ColonyPopulationTurnoverPressure.cs`; `ColonyHabitatSupportBurden.cs`; environmental computations already ported in `species_environment.hpp`. Use original C# to generate expected fixtures, never use native output as oracle.

Keep four authored biological profiles in named fields, including raw life-history timings and metabolic fractions/dormancy. Compute demographic pace from original Terran-normalized ratios and cube root, clamped .20..1.80. Metabolic envelopes use founding unadapted population and original baseline/rest/peak/dormancy arithmetic, not substitute economy units. PopulationMillions*kg is million kg. Do not conflate natural-colonization viability with SettlementSuitability; the policy enum has exactly Unsuitable/HabitatSupportedFallback/NaturallyViable. Wrapper natural requires original canonical naturally-colonizable and no pre-warp natives; fallback requires legacy flag, solid surface, and no natives.

Scalar colonies with null body retain neutral environmental turnover and no habitat environment record. Exact body lookup must match both body ID and system ID; missing/mismatched exact bodies fail cleanly instead of guessing a replacement. Naturally viable bodies apply sqrt(naturalHabitability); fallback and unsuitable bodies remain environmentally neutral for current demographic policy. Raw requirements retain all six mitigation flags/counts and population-weighted demands. No suppression of invalid population/species/IDs. Preserve current validation and boundaries; clarify expected native exception-type/message differences rather than treating any exception as success.

Test all four authored profiles and formula outputs from actual C#, normal/very small populations, all dormancy modes present in catalog, all four ideal environments, stressed naturally viable versus habitat fallback/unsuitable/pre-warp/non-solid worlds, exact versus legacy neutral records, missing/wrong-system body, invalid population/unknown species/negative IDs, flag/count consistency and entire immutable input colony. Include real seeded Earth/Luna/Mars and all species to expose consequential integration defects. Compare optional fields, booleans, enum mappings, strings and derived values; use meaningful numerical tolerance. Do not overwrite current gameplay or prior fixtures.
