# Strategic director and runtime draft boundary (gate 037)

This draft composes the accepted input builder, planner, intent builder, and preference providers. It adds no new planning, capability, exploration, or knowledge policy. A single observer-local knowledge callback is shared by the scheduled runtime; an absent callback produces the source empty knowledge snapshot at the requested tick.

The director validates future knowledge before civilization membership, then builds own state, requests the cached plan, and builds intent. The runtime validates finite nonnegative delta days before campaign reset, resets all derived state on seed change, accumulates strategic days, and visits eligible civilizations in stable ascending ID order. Player and seeded-ancient civilizations are skipped. Zero-day calls still process due civilizations. Each successful review publishes industry first and shipbuilding second before recording the next review tick.

Native conversion rejects nonfinite or out-of-range accumulated strategic days before converting to a tick, avoiding undefined behavior. The exclusive upper bound is `0x1p63`: the immediately preceding representable double is accepted, while exact 2^63 and cumulative rounding to that value are rejected. A rejected delta is not accepted into the clock. Validation still occurs after campaign selection, so a changed seed has already reset the clock, schedules, planner cache, and both providers when the rejection is reported; a subsequent safe call starts that newly selected campaign normally.

The actual C# oracle runs with `CurrentCulture` and `CurrentUICulture` fixed to invariant culture. Its `double.MaxValue` cast behavior is retained as source-only metadata because C++ conversion at that magnitude would be undefined without the native boundary. Null-world behavior is likewise source-only. The replay covers complete normalized reviews, both provider views, cache-visible scheduling consequences, callback order, and full serialized relevant world inputs before and after every operation.
