# Massive combat engine source parity

This gate ports the authoritative fixed-tick `MassiveCombatEngine` and its independent `MassiveCombatClock` onto the maintained owned `MassiveCombatBattleState`. It does not begin or reconcile campaign encounters, expose observer views, or claim tactical player-session routing.

The retained actual-source fixture covers clock speeds and frame clamping; asymmetric and nonhostile relationships; every order validation class plus friendly protection, withdrawal and surrender mutations; elapsed-time validation before state validation; legacy ship-count materialization; pending fractions, catch-up cap and overflow; pre-movement spatial indexing; missile flight and interception; damaged cohorts and important vessels; warp escape and interdiction; finite extreme coordinate conversion; protected-target empty-neighborhood behavior; fractional non-axis normalization and protected movement; and a serialized, damaged, in-flight, pending-time multitick continuation. It compares the complete battle state, events and returned metrics. Source `LastMetrics` is `JsonIgnore` and has no production consumer; native returns the full value without adding it to durable state. A retained-metrics row proves a later failed call does not modify the previously returned value and confirms the source transient property also remains unchanged.

`MassiveCombatEngine` owns its hostility callable in stable move-only Pimpl storage. References captured by that callable must outlive the engine and remain unmoved. Native probes exercise construction, move construction, move assignment, callback invocation, and detached order inputs.

The fixture contains 45 native rows and no source-only rows. Its five source-file fingerprints and its own SHA-256 are verified before and after replay. Debug and Release use `/W4 /WX /permissive- /fp:precise /utf-8` with explicit isolated object and PDB paths; both pass 45/45 rows. Missing arguments, fixture and source paths fail with a nonzero exit and useful paths. The retained managed generator is `tests/Stellar.MassiveCombatEngine.ParityGenerator`; rebuilding the actual `Game.csproj` and running it twice produced byte-identical fixtures.

Float-valued source fields compare after exact IEEE-754 binary32 reconstruction from the source serializer's shortest round-trip decimals. Integers compare at their full widths, and double-valued clock/pending/simulated time uses absolute tolerance `1e-10`. This is needed because the JSON library expands native binary32 values to binary64 decimal text; it does not relax tactical state arithmetic.

The finite-extreme-coordinate row proves the source-observed `float.MaxValue -> Int32.MinValue` cell conversion and empty-neighborhood result. Native uses explicit two's-complement wrapping for the surrounding cell arithmetic and loop increments, avoiding signed C++ overflow while retaining that observed result.
