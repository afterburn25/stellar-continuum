# Logistics and industrial allocation migration

Next gate after funded economy. Frozen interfaces are `core/include/stellar/core/logistics.hpp` and `industry_allocation.hpp`. Port the existing `Economy/LogisticsRoutePlanner.cs`, `LogisticsFlowAllocator.cs`, `EconomyLogisticsView.cs`, `HomeSystemLogisticsNetwork.cs`, `CivilizationLogisticsCoverage.cs`, `CivilizationOperatingCapacity.cs`, and `Industry/IndustryAllocation.cs`. Preserve all rates, units, thresholds, source ordering, authorization, and error behavior. No new freight corridors or resource simulation are invented. Freight fleet transit and combat repair remain later dependencies.

Routing owns graph copies; rebuild when infrastructure/access changes. Graph IDs are unique, links must reference owned nodes and finite nonnegative capacity/time even when disabled, and cache capacity must be positive. Unknown query nodes reject; cross-empire queries return no route. Same-node routes have zero time and infinite capacity and are not cached. Cache both reachable and unreachable distinct-node results with strict bounded LRU; return detached values so callers cannot mutate cached paths. Queries are owner-thread only. Independent planners can run on separate workers later.

Preserve shortest-transit routing: adjacency sorted by link ID, enabled positive-capacity same-owner edges only, equal-cost alternatives do not replace previous edges. Equal queue priorities are not promised FIFO by the source runtime. The C# source uses .NET8's quaternary heap; compare equal-path fixtures with >4 pending nodes and stale entries. If required, translate only the minimal relevant queue mechanics with attribution to the existing MIT-licensed .NET source: https://github.com/dotnet/runtime/blob/v8.0.0/src/libraries/System.Collections/src/System/Collections/Generic/PriorityQueue.cs. Do not assume std::priority_queue tie ordering is equivalent. No new generic scheduler is needed.

Daily flow preserves source algorithm, not a new max-flow solver: validate/aggregate offers in insertion order; stable sort demands by priority descending then node ID; skip self-supply; compute shortest-route candidates, sort by transit time then remaining capacity descending then source ID; recompute shared capacities as allocations proceed. Saturated shortest paths are not silently rerouted onto longer alternatives. Duplicate demand IDs retain source overwrite behavior for unmet-demand dictionaries, not summed unmet demands. Ordered node quantities preserve first insertion position and last assignment value. Track disabled-link capacity, reject duplicate allocator links and unknown route link references. Inputs are immutable; only planner cache mutates.

Existing coarse logistics views use infrastructure/stability/population and actual ledger throughput, not a fabricated item warehouse. Preserve population minimum .001, infrastructure .1..5 and stability .1..1.2, support and local-capacity formulas, .70/.95 coverage thresholds, .10 minimum handling and existing orbital/automation bonuses. Home colonies sort by ID; first represented home colony remains Homeworld by source convention. Build only represented orbital hub/shipyard/resource nodes and exact fallback home connections. No extrapolated interstellar lanes. External systems sort by system ID and colony ID, preserve worst-condition and unrepresented-support totals. All views are read-only and may consume existing funded-economy ledger projections, but do not deliver freight, grow population or mutate reserves.

Industry uses the existing two-consumer weighted max-min allocator: validate finite nonnegative stock/demand, positive finite weights, preserve numeric operation/reflow order and totals. Campaign priority uses first economy's optional persisted selection, otherwise explicit supplied fallback; no implicit AI implementation. Ownership command checks unknown enum first, actor/target ownership second, existing economy third; rejected commands do not mutate. Explicit persisted priorities map 1:1,3:1,1:3; invalid persisted values throw. Operating funding uses first economy, defaults1 when absent, clamps finite0..1, and returns0 for nonfinite. These pure helpers do not advance construction or shipbuilding timers.

Validation uses actual preserved C# public calls with immediate cloned snapshots and activation assertions. Routing fixtures must cover all node/link kinds, missing and duplicate IDs, disabled/zero/directed/foreign links, validation even when disabled, same-node/cross-owner/unreachable, equal-cost alternatives and >4 queue ties, stale entries, cycles, LRU capacity/hits/eviction including null routes and query sequence count. Flow cases need priority conflicts, shared bottlenecks, multiple suppliers, identical-time ordering, duplicate offers/demands, zero/self-supply, saturation with a longer alternative, disconnected and missing-node cases, caller data nonmutation, real home-network integration.

Views cover actual seeded Earth/Luna/Mars, ancient projects, no home colonies, remote colonies, no orbital hub fallback, each infrastructure project, clamped and threshold states, shortages/surplus, sorted output and absent required state. Industry cases cover no demand, oversupply, one consumer, proportional scarcity, reflow both directions, persisted/fallback priorities, authorization/rejection nonmutation, invalid quantities and weights. Compare all fields/paths/sets/ordered sequences, numeric tolerance explicit. Parse outside expected-error catches; comparisons and activation assertions also outside catches; no references to expired local state in deferred checks.
